================================================================================
TABLE 2: LATENCY METRICS
================================================================================
Metric                      Value        Unit / Description & Formula
--------------------------------------------------------------------------------
PE pipeline latency (L)     2            Clock cycles
                                         (Cycle 1: multiplication into m_reg;
                                          Cycle 2: accumulate into psum_out)

First-output latency        32           Clock cycles
                                         From start of activation streaming to
                                         first valid output at PE(15, 0).
                                         Formula: 2 x R = 2 x 16 = 32 cycles.

Wavefront latency           47           Clock cycles
                                         From first input until first complete
                                         vector wavefront exits across all 16 cols.
                                         Formula: 2R + C - 1 = 32 + 15 = 47 cycles.

Tile completion latency     K + 46       Clock cycles
                            (e.g., 62    Total cycles to finish a tile of K vectors.
                            for K=16)    Formula: (K - 1) + 2R + (C - 1) + 1.

Pipeline fill               32           Clock cycles
                                         Cycles needed to load vertical pipeline
                                         before the first output row emerges.
                                         Formula: 2 x R = 32 cycles.

Pipeline drain              47           Clock cycles
                                         Cycles to fully flush all in-flight 
                                         computations after the final input vector.
                                         Formula: 2R + C - 1 = 47 cycles.

Weight preload latency      16           Clock cycles
                                         Cycles to shift a full 16x16 weight matrix
                                         into shadow registers (1 cycle/row x R).

Weight update latency       1            Clock cycle
                                         Parallel shadow-to-active register transfer
                                         via 1-cycle weight_swap_en pulse.
